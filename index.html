Explain It

  1. How does your app change a sound wave into binary?
    My app samples the wave, changes each sample into a level, and converts each level into binary. The three steps are sampling, quantization, and binary encoding.
  2. Which gives more detail, 2 bits or 6 bits?
    Six bits gives more detail because it has 64 levels, while 2 bits has only 4. With more levels, the binary follows the wave's height more closely, but it also uses more bits.
  3. Which test has the longest wavelength?
    Test B has the longest wavelength at 1.72 m. Wavelength and frequency are inversely related, so a lower frequency produces a longer wavelength.
  4. What was the hardest stage to build?
    The hardest part was converting the sample levels into the correct binary values. I fixed it by following the formulas carefully and adding leading zeros.
